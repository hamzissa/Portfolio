Street Food Directory

Spring Boot web application for browsing and managing street food vendors, built for university coursework. Uses an MVC architecture with JPA entities persisted to MySQL and server-rendered JSP views.

Key Features:

  • Full create, edit and delete for vendors, dishes, reviews, photos and awards
  • Search vendors by name or by dish
  • Dishes with price, spice level and tags such as "Vegetarian" or "Hidden Gem"
  • Server-side validation, including duplicate vendor name checks
  • Relational data model with one-to-many, one-to-one and many-to-many JPA mappings
  • Java 21
  • Spring Boot
  • Spring Data JPA
  • MySQL
  • JSP
  • Gradle
